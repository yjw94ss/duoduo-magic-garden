# 🌈 朵朵的魔法花园

一款为 **4 岁小朋友**量身定做的中文 3D 网页游戏。HTML5 + JavaScript + Three.js，纯前端，无需后端、无需联网、无需安装任何东西。

## 📱 手机上怎么玩

**用手机浏览器打开上面的网址就行**（需要联网，网址是 GitHub Pages 提供的 HTTPS 链接）。

- **iPhone / iPad**：Safari 打开 → 点「开始游戏」
- **安卓手机**：Chrome 打开 → 点「开始游戏」

**建议加到主屏幕**，像 App 一样一点就开：

- iPhone：Safari 底部「分享」→「添加到主屏幕」
- 安卓：Chrome 右上角「⋮」→「添加到主屏幕」

> 💡 进游戏后要**点一下「开始游戏」大按钮**才会有声音，这是浏览器的规定（音频必须由用户点击触发）。

**进度会存在手机浏览器里**（换设备不同步，这是为了保护孩子的隐私，不做账号、不上传任何数据）。

## 🚀 怎么玩

### 方式一：双击直接打开（最简单）

双击 `index.html`，用 Chrome / Edge / Safari 打开即可。
Three.js 已经放在 `vendor/` 目录里，**完全离线可用**。

### 方式二：本地服务器（推荐，兼容性最好）

在这个文件夹里打开终端，执行任意一条：

```bash
# Python（Mac / Linux 自带）
python3 -m http.server 8000

# Node.js
npx serve .
```

然后浏览器访问 <http://localhost:8000>

### 支持的设备

| 设备 | 操作方式 |
|---|---|
| 电脑 | 鼠标点击 |
| iPad / 平板 | 触摸点击 |
| 安卓手机 | 触摸点击 |

**不需要键盘。** 所有操作都是点一点。

## 💗 给家长的设计承诺

**绝对没有这些东西：**

- ❌ 死亡、受伤、哭、Game Over、失败惩罚
- ❌ 红色叉叉、"错误！""失败！"
- ❌ 武器、怪物、追逐、恐怖音效、突然惊吓
- ❌ 付费、充值、广告、抽卡、商城、体力
- ❌ 倒计时催促、需要连续快速点击
- ❌ 聊天、交友、外部链接、陌生人诱导
- ❌ 收集姓名、照片、地址、手机号等任何个人信息

**答错时会发生什么？**

错误答案会**轻轻左右摇一摇**，然后温柔地说一句"再试试呀"或"再看看，红色在哪里呀？"，然后**重新可以选**。没有红叉，没有惩罚，没有中断。

**孩子卡住不动 10 秒？**

小星星会**飞到目标方向**、地面冒出闪光、所有小动物挥手示意。**不会有任何催促或倒计时。**

## 👨‍👩‍👧 家长模式

右上角有个**很不显眼的灰色小齿轮**（34px、半透明）。

**长按 1.6 秒**才能进入，防止孩子误触。进入后可以看到：

- 今日游戏时长（分钟）
- 已完成小游戏数量
- 颜色认知完成情况
- 数字认知完成情况

还可以一键清空本机记录。

> 所有数据只存在**本机浏览器的 localStorage**，不上传任何服务器。

## 📁 项目结构

```
duoduo-garden/
├── index.html          页面结构（LOGO / 角色选择 / HUD / 弹层）
├── style.css           样式（巨大按钮、马卡龙色系、触屏适配、安全区）
├── vendor/
│   └── three.min.js    Three.js r160（本地化，离线可用）
└── js/
    ├── audio.js        全部音效由 WebAudio 实时合成，零音频文件
    ├── levels.js       地图注册表（7 张地图，1 张已实现 + 6 张预留）
    ├── world.js        彩虹花园程序化生成（几何体拼模型）
    ├── player.js       主角模型（4 种造型）+ 点击寻路 + 碰撞 + 相机
    ├── npc.js          6 种小动物 + AI 伙伴「小星星」
    ├── minigames.js    5 个小游戏 + 粒子特效 + 任务管理器
    ├── rewards.js      存档 + 魔法星星 + 宝箱
    ├── ui.js           界面管理（含家长模式长按）
    └── main.js         状态机 + 拾取 + 主循环
```

**没有使用任何美术资源文件** —— 角色、动物、房子、彩虹、宝石全部由 Three.js 基础几何体（球体/圆柱/圆锥/圆环/方块）程序化拼出来，所以不会因为缺模型而跑不起来。

## 🗺 地图结构

彩虹花园分三个圈，**站在中心仍能一眼看全主要目标**：

| 区域 | 半径 | 有什么 |
|---|---|---|
| **核心活动区** | 0 – 32 | 彩虹门、小房子、池塘+斜木桥、花田、5 个任务 NPC、长椅、蘑菇、花丛 |
| **中环探索区** | 32 – 56 | 3 座凉亭、糖果树丛、圆石群、彩虹秋千、蘑菇圈 |
| **外环景观区** | 56 – 82 | 成片糖果林、起伏丘陵、密集气球与云朵、边界树墙 |

三条环形小路（半径 30 / 46 / 64）串起各区，还有一条直路通向彩虹门。

**性能**：地图扩大后，55 单位以外的景物会自动关闭阴影计算
（`world.js` 的 `cullShadowsByDistance`），draw calls 从 890 降到 ~550，60 FPS 稳住。

## 🤖 接入大模型（已预留接口）

`js/npc.js` 里的 `AICompanion` 已经是模块化的，当前用本地儿童对话库（完全离线）。将来接大模型只需一行：

```js
DDAICompanion.setRemoteTalker(function (ctx) {
  return fetch('https://api.example.com/v1/chat/completions', {
    method: 'POST',
    headers: { 'Authorization': 'Bearer YOUR_KEY' },
    body: JSON.stringify({
      model: 'gpt-4o-mini',
      messages: [
        { role: 'system', content: '你是4岁小朋友的游戏伙伴，说话要温柔、短句、多用叠词。' },
        { role: 'user', content: ctx.text }
      ]
    })
  }).then(r => r.json())
    .then(d => d.choices[0].message.content);
});
```

游戏其它部分**完全不用改**。
